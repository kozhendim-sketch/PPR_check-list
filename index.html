Чек-лист платформы PPR

⚠️ PPR находится на тестовом сервере. Данные обновляются раз в неделю по понедельникам.
Проверка доступа к платформе
  • RGM может зайти на платформу
  • ARGM может зайти на платформу
  • SM и ниже — не может зайти на платформу
  • Выбор месяца активен
  • Есть возможность выбрать в фильтрах «Структура+1» (посмотреть любой ресторан из состава своей территории)
  • Внести изменения в состав соседнего ресторана нельзя
Вкладка «Структура»
  • «План по матрице» — соответствует плановому количеству людей в каждой должности согласно People KPI
  • «Факт» — фактическое количество людей в должности из БОСС (без «0» ставок)
  • «Вакантно» — «План по матрице» − «Факт»
  • «FTR МНГ» — «Факт» / «План по матрице» × 100% (кратно выбранному месяцу)
  • «Количество на обучении» — соответствует вкладке «Обучение»
  • «FTR МНГ с учётом IT» — («Факт» + «Количество на обучении») / «План по матрице» × 100%
  • «Факт по ставкам» — фактическое количество людей в должности кратно оформленной ставке
Вкладка «Обучение»
  • «IT на должность» — соответствует должности, на которую проходит обучение в Академии
  • «Начало обучения» — дата назначения модуля из Академии
  • «Прогресс обучения» — количество модулей со статусом «Пройдено» от всего модулей в программе обучения (0/1 или 1/1)
  • Даты «Школы Лидерства 1», «Школы Лидерства 2» и «Школы РОСТ» соответствуют данным Академии
  • Дата и процент чек-листов «Квалификация» и «Сертификация» соответствуют Академии
Вкладка «Кадровый резерв»
  • В разделе есть все сотрудники с пройденными Up-оценкой, HiPo-интервью и завершённым обучением на следующую позицию
  • «Позиция» — соответствует текущей должности из БОСС
  • «Роль на обучении» — соответствует роли из Академии, на которую завершено обучение
  • «HiPo-интервью» — соответствует результату интервью
  • «Обучение завершено» — соответствует дате завершения обучения в Академии (присвоение сертификата согласно следующей роли)
Раздел «Продвижение МНГ»
  • В «Продвижении МНГ» отображаются все действующие менеджеры ресторана и корректны данные
  • «Позиция» — текущая роль из OneTime
  • «Up-оценка» — дата последней Up-оценки
  • «HiPo-интервью» — дата последнего интервью
  • «G&R Текущего периода» — данные из раздела GR (только закрытые периоды, после 21 числа) — соответствие с TeamUp
Раздел «Структура рядовых сотрудников»
  • В структуре рядовых отображаются все действующие штатные сотрудники и «Услуги» с гражданством ЕАЭС (Армения, Казахстан, Россия, Киргизия, Беларусь)
  • «Рядовые РФ» — количество сотрудников с гражданством ЕАЭС (включая «Услуги»)
  • «18-» — количество сотрудников младше 18 лет
  • «18+» — количество сотрудников старше 18 лет
  • «Хочу развиваться» — количество и % (сверить с TeamUp)
  • «Универсалы» — количество сотрудников с 4 сертификатами из Академии (Кухня, Обслуживание, Цыпленок, Зал) — сверить с Академией
  • «Инструктора» — количество сотрудников с сертификатом «Инструктор» из Академии — сверить с Академией
  • При нажатии кнопки «Скрыть отсутствующих» появляются все сотрудники в Декрете и в Армии
  • При нажатии кнопки «Только штатные» видны только штатные с гражданством ЕАЭС
  • Сертификации по станциям соответствуют данным Академии для каждого сотрудника
Проверка доступа к платформе
  • Доступ есть
  • Актуальный состав ресторанов территории доступен
  • Выбор месяца активен
  • Есть возможность выбрать в фильтрах «Структура+1» (посмотреть любую территорию из состава своего маркета)
  • Внести изменения в состав соседней территории нельзя
Вкладка «Структура»
  • «План по матрице» — соответствует People KPI
  • «Факт» — данные из БОСС (без «0» ставок)
  • Активна кнопка просмотра пофамильного списка — фамилии соответствуют реальным людям
  • «Вакантно» — «План по матрице» − «Факт»
  • «FTR МНГ» — «Факт» / «План по матрице» × 100%
  • «Количество на обучении» — соответствует вкладке «Обучение»
  • «FTR МНГ с учётом IT» — («Факт» + «Количество на обучении») / «План по матрице» × 100%
  • «Факт по ставкам» — с учётом оформленных ставок
Вкладка «Обучение»
  • В разделе есть все сотрудники с пройденными Up-оценкой, HiPo-интервью и назначенным обучением в Академии
Вкладка «Продвижение»
  • «Вакантно» — количество открытых вакансий по каждой должности
  • «План выбытия/риски» — количество людей, перенесённых в корзины (Выбытие, Декрет, Переводы вне территории)
  • «КР» — сотрудники с пройденными Up, HiPo, завершённым обучением и сертификацией на следующую позицию
  • «На обучении (IT)» — сотрудники с пройденными Up, HiPo и начатым обучением в Академии
  • «Хочу развиваться» — сотрудники, нажавшие кнопку (рядовые) + менеджеры с положительным статусом в Up-оценке
  • «Up-оценка» — количество сотрудников и менеджеров с проведёнными Up-оценками
  • «HiPo-интервью» — количество сотрудников и менеджеров с проведёнными HiPo интервью
Вкладка «Фактическая структура»
  • Распределение менеджеров по ресторанам актуально
  • При отметке МНГ как кадрового резерва сотрудник отображается в разделе «Кадровый резерв»
Вкладка «Планирование»
  • При старте планирования распределение соответствует фактической структуре
  • Работает перетаскивание на свободные вакансии
  • В разделе «Декреты» отображаются все МНГ территории в декрете
  • После перехода на другую вкладку и возврата изменения сохраняются без кнопки «Сохранить»
Вкладка «Структура рядовых сотрудников территории»
  • Количество «Хочу развиваться» соответствует TeamUp
  • Перетаскивание на свободные вакансии работает
Проверка доступа к платформе
  • Доступ есть
  • Актуальный состав ресторанов маркета доступен
  • Выбор месяца активен
  • Кнопка «Подтвердить план» в Планировании активна
  • Есть возможность выбрать в фильтрах «Структура+1» (посмотреть любой маркет и ресторан из Дивизона)
  • Внести изменения в состав соседних маркетов нельзя
Проверка данных из БОСС
  • Соответствие структуры МНГ по каждому ресторану и дат назначения
  • Соответствие декретников по каждому ресторану
  • Соответствие ролей из OneTime по каждому ресторану
  • Соответствие структуры РФ сотрудников и ЕАЭС данным из БОСС
  • Соответствие 18+ и 18- сотрудников данным из БОСС
Проверка данных из TeamUp
  • Соответствие количества в разделе «Прод
